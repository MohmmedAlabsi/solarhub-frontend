## الصفحات

| المسار | التنفيذ |
| --- | --- |
| `/admin` و`/admin/dashboard` | لوحة الإدارة، تاريخ اليوم بتوقيت الرياض، أرقام محسوبة من بيانات القوائم، وروابط المتابعة بفلاتر مدعومة |
| `/admin/users` | بحث وحالة حساب، إضافة مكتوبة الأنواع بتحقق، تغيير الحالة، تأكيد الحذف، ترقيم وCSV مفلتر |
| `/admin/stores` | المسار الموجود في السايدبار للموردين؛ بحث واعتماد ونوع متجر، إضافة وحذف مؤكد، تفاصيل وقبول ورفض بسبب إلزامي |
| `/admin/engineers` | جدول وتخصصات وترخيص، إضافة وحذف مؤكد، تفاصيل وشهادات، اعتماد ورفض وتاريخ اعتماد صحيح، فلتر المراجعة من اللوحة |
| `/admin/services` | المسار الموجود في السايدبار لطلبات الخدمات؛ بحث وحالات وتصدير، نافذة بيانات العميل والموقع والمرفقات والعروض، دون ترسية إدارية |
| `/admin/reviews?tab=suppliers` و`?tab=engineers` | تبويبان في صفحة واحدة، بحث وترقيم مستقل، حفظ query، واعتماد محلي قابل للوصول بلوحة المفاتيح |
| `/admin/notifications` | بحث وفلاتر وترقيم وإجمالي، نافذة إرسال مع تحقق ومنع التكرار، وإشعار محاكى دون نسبة قراءة مصطنعة |
| `/admin/settings` | حفظ وإلغاء إعدادات المنصة محليًا، حالة صيانة تجريبية موضحة، كثافة جداول مفعلة واستعادة الافتراضي؛ اللغة والمظهر غير المدعومين موضحان |

## إعادة الاستخدام والتكامل

- أُعيد استخدام AdminSidebar وAdminSidebarLink وAdminHeader وAdminFooter وFormField وAppToast.
- وُسع AdminModal نفسه لاحتواء Tab وShift+Tab وEscape وعزل الخلفية ومنع تمريرها واستعادة التركيز، مع جسم قابل للتمرير وفوتر متاح. أضيف خيار لون رأس النافذة وحالة المعالجة دون استبدال المكون.
- وُسع AdminBadge بخيار tone اختياري يحافظ على الحالات الافتراضية السابقة.
- وُسع AdminPagination بخيار إخفاء شريط التقدم؛ يبقى ظاهرًا افتراضيًا للصفحات القائمة.
- مصدر الإدارة المكتوب الأنواع في useAdminWorkspace وapp/data/admin-workspace.ts منفصل عن بيانات دليل الزوار. فُصل منطق الإضافة والاعتماد والإشعارات والإعدادات في composables.
- بيانات طلبات الشراء الثمانية استُخرجت كما هي إلى app/data/admin-orders.ts؛ تستخدم صفحة الطلبات واللوحة useAdminOrders، مع فلتر المتابعة وعدّاد وترقيم مشتقين من السجلات. لا إعادة تصميم لهذه الصفحة.
- CSS الجديدة محصورة بأسماء واجهات الإدارة الجديدة. خصائص الكثافة لا تغيّر جداول الأدوار الأخرى.

## التفاعلات والحدود

كل السجلات والإجراءات الجديدة تجريبية في ذاكرة الجلسة. تحديث الصفحة يعيد بيانات البداية. لا API مخترع ولا إرسال رسائل أو إنشاء حسابات على الخادم ولا تخزين حساس في LocalStorage.

CSV ملف فعلي بترميز UTF-8 مع BOM ويعكس النتائج المفلترة كلها، ويقتبس الفواصل والاقتباسات ويحمي من تفسير القيم كصيغ.

المرفقات بلا ملفات فعلية معروضة بصراحة كغير متوفرة، دون روابط تنزيل معطوبة. تفعيل الصيانة على الخادم والإشعارات الحقيقية ونسب القراءة وحفظ الإعدادات الدائم والملفات يحتاج API معتمدًا. ترجمة الواجهة الإنجليزية والوضع الداكن غير منفذين ولا يُعرض نجاح وهمي لهما.
